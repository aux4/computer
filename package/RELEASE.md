# Release notes

- The playbook action file (`package/actions/computer.yaml`) now passes `--app` via `aux4/playbook`'s `param(app)` instead of hand-quoting `'${app}'`/`'{{app}}'`: the flag is omitted entirely (not passed empty) when neither `with app` nor a per-step `in {app}` sets one, and any app/text/element value survives verbatim (apostrophes, spaces, `$(...)`, backticks, quotes) through aux4-core-style escaping.
- Playbook support: `aux4/computer` now depends on `aux4/playbook` and provides a `computer` playbook context (`package/actions/computer.yaml`, bound via `playbook:actions`, private so it never loads globally). Use it from a script with `on context computer [with app "App"] ... end of context` and plain verbs (`open`, `focus`, `quit`, `state`, `find`, `wait for`, `click on`/`click at`, `type`, `shortcut`/`press`, `scroll`, `drag`, `menu`, dialog buttons, `screenshot`, `ocr`, `clipboard copy`/`paste`/`read`), each calling the front door `aux4 computer ...` (stop switch + action log apply). `with app "X"` on the block sets the default target for every step; `... in {app}` on an individual step overrides it for that line only; omit both for full access (frontmost app / whole screen). `click on {name}` resolves the label to coordinates via `find` first, since `click` has no name flag.
- `aux4 computer conformance` works on Windows: the suite directory is passed to `aux4 test run` with forward slashes, so a Windows path keeps its separators.
- New package: `aux4 computer <command>` runs the computer-use command surface on the provider for this OS (`mac`, `linux`, `win`), with `--provider` to pick one; flags pass through unchanged.
- Clear errors when the provider is missing (names the package to install) or speaks another contract version; providers without `info` are used and listed as `legacy`.
- `aux4 computer providers`, `info` and `notes`.
- Shared stop switch and action log across every provider: `aux4 computer stop`, `resume`, `log`; the switch is checked before any state-changing command is dispatched.
- Provider contract v1 conformance suite and `aux4 computer conformance` to run it from a provider repository.
- AI skill: `aux4 ai skill computer prompt` (the generic method plus the current provider's notes).
